# SWOLVATION marketing

The launch campaign for the first drop: strategy, creative, scripts, production records and the plan for posting and testing.

**Start here:** `production_manifest.md` lists every finished ad with its length, format, download link and status, plus everything that's limited or not made yet.

| Folder | Contents |
| --- | --- |
| `brand_strategy/` | `brand_direction.md` (look, type, voice, lines, rules) · `launch_strategy.md` (launching with no following, content by platform, weekly optimization) |
| `creative_concepts/` | `campaigns.md`: The Underground, The Vintage Era, The New Generation, with hooks |
| `scripts/` | Timed scripts for every ad, plus alternate hooks for testing |
| `storyboards/` | `shot_list.md`: every keyframe and shot, Higgsfield job ID, model, prompt pattern and QA result |
| `product_references/` | Which product photos are the source of truth, and what a real shoot should add |
| `marketing_calendar/` | 30-day posting calendar |
| `performance_testing/` | Metrics, test matrix, log template, how to read results |
| `final_ads/`, `instagram/`, `tiktok/`, `youtube/`, `product_photography/`, `thumbnails/`, `generated_footage/`, `approved_footage/` | Local homes for media once it's downloaded. Media files are git-ignored here; the masters live in Higgsfield (see the manifest) |

Rules for every asset:
- No people.
- Real product prints only, checked against the real photos.
- All on-screen text is typeset (Big Shoulders and Archivo, the website's fonts).
- No invented reviews, discounts, scarcity or fabric claims.
- No "available now" until checkout works.
